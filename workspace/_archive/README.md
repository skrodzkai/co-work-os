# _archive — retired projects

Finished or abandoned projects move here **whole** — folder, decision log, outputs, everything.
Don't delete projects — move them here; and never cherry-pick files out of a project on its
way in.

Two reasons this folder earns its space:

1. **The decision logs keep answering questions.** "How did we handle this in last year's
   cycle?" is a Claude query against `_archive/`, not an archaeology project.
2. **Retention policy has one place to point at.** Your records-retention rules apply to
   `20_outputs/` folders in here exactly the way they apply to any other team document store.

Review annually; genuinely dead material can be moved to cold storage by the workspace owner.
